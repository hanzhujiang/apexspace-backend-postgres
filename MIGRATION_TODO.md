### Step 2 — Start PostgreSQL with Docker

`docker-compose.yml` is at the repo root. It starts PostgreSQL 16 with the credentials above.

```bash
docker compose up -d
```

Verify it is running:

```bash
docker ps | grep apexspace_postgres
# Should show the container running on 0.0.0.0:5432
```

Test the connection (optional, requires `psql` client):

```bash
PGPASSWORD=apexspace_dev psql -h 127.0.0.1 -p 5432 -U apexspace -d apexspace_crm
```

Or connect with TablePlus / DBeaver / pgAdmin using the same credentials.

### Step 3 — Install dependencies

```bash
npm install
```

### Step 4 — Create tables (Sequelize sync)

This reads all model definitions in `src/db/index.js` and creates the tables:

```bash
npm run db:sync
```

`db:sync` calls `syncDatabase({ alter: true })` which creates missing tables and adds missing columns without dropping data. Safe to re-run.

> **Note**: In production, set `alter: false` and manage schema changes manually with SQL migrations. Never run `force: true` (drops all tables).

### Step 5 — Seed reference data

```bash
npm run setup-db
```

This runs `src/setup/setupDb.js` and seeds:
- Permission rows for all non-owner roles
- All default settings from `src/setup/defaultSettings/**/*.json`
- Default tax (`Tax 0%`)
- Default payment mode (`Default Payment`)

All inserts are idempotent — safe to re-run.

### Step 6 — Create the owner admin

```bash
npm run create-admin -- --email=you@example.com --password=yourpassword --name=YourName
```

This creates the first `owner`-role admin account.

### Step 7 — Start the server

```bash
npm run dev     # development (nodemon, SQL logging on)
npm start       # production
```

## Phase 0B — PostgreSQL Table Design (MongoDB → PostgreSQL Mapping)

All tables are defined in `src/db/index.js` via Sequelize. This section documents every table, its columns, and what MongoDB document/field it replaces.

> **Column type notes for Postgres**:
> - `VARCHAR` below = Sequelize `DataTypes.STRING` → `VARCHAR(255)` in Postgres (no length penalty vs `TEXT` on Postgres — kept VARCHAR for schema clarity).
> - `JSON` columns use `JSONB` (binary, indexable). Sequelize `DataTypes.JSONB` → `JSONB` in Postgres.
> - `INT PK AI` = `SERIAL` / `INTEGER … GENERATED BY DEFAULT AS IDENTITY` in Postgres. Sequelize handles both via `autoIncrement: true`.
> - `BOOL` = native `BOOLEAN` in Postgres (true/false, not 0/1 as in MySQL).
> - `ENUM` creates a dedicated type per column in Postgres (e.g. `enum_admins_role`). Altering ENUM values after creation requires `ALTER TYPE ... ADD VALUE`; plan values up front.

## Group 1 — Settings Middleware

These are helper functions imported by invoice/quote/payment controllers. Port these first so dependent controllers work.

### TASK 1 — `src/middlewares/settings/increaseBySettingKey.js`

**Purpose**: Fire-and-forget increment of a counter setting (e.g. `last_invoice_number`). Called after invoice/quote creation.

**Current Mongoose pattern**:
```js
await Model.findOneAndUpdate(
  { settingKey },
  { $inc: { settingValue: 1 } },
  { new: true }
);
```

**Sequelize implementation**:
The Setting model has two value columns: `settingValue` (JSON/TEXT, for strings/objects) and `integerValue` (INTEGER, for numeric counters). The `$inc` on numeric settings targets `integerValue`.

```js
const { models } = require('@/db');

const increaseBySettingKey = async ({ settingKey }) => {
  try {
    if (!settingKey) return null;
    const [count] = await models.Setting.increment('integerValue', {
      by: 1,
      where: { settingKey },
    });
    return count;
  } catch {
    return null;
  }
};

module.exports = increaseBySettingKey;
```

> **Note**: `models.Setting.increment()` returns `[affectedCount]`. If you need the updated row back, follow with a `findOne`. But since this is fire-and-forget, you do not need the return value.

### TASK 5 — `src/middlewares/settings/updateBySettingKey.js`

**Purpose**: Updates a setting's value by key. Used internally.

**Sequelize implementation**:
```js
const { models } = require('@/db');

const updateBySettingKey = async ({ settingKey, settingValue }) => {
  try {
    if (!settingKey || settingValue === undefined) return null;
    const [, [updated]] = await models.Setting.update(
      { settingValue },
      { where: { settingKey }, returning: true }
    );
    return updated || await models.Setting.findOne({ where: { settingKey } });
  } catch {
    return null;
  }
};

module.exports = updateBySettingKey;
```

> **Note**: Postgres supports `UPDATE … RETURNING` natively, so `models.Setting.update(…, { returning: true })` returns `[affectedCount, [updatedRows]]`. The fallback `findOne` is still there for safety but will usually be unused.

```js
const list = async (req, res) => {
  // Seed missing roles
  await Promise.all(
    NON_OWNER_ROLES.map((role) =>
      models.Permission.findOrCreate({
        where: { role },
        defaults: { permissions: DEFAULT_PERMISSIONS },
      })
    )
  );
  const docs = await models.Permission.findAll({
    where: { role: NON_OWNER_ROLES },  // Sequelize accepts array for IN
    order: [['role', 'ASC']],
  });

const update = async (req, res) => {
  const { role, permissions } = req.body;
  if (!role || !permissions) {
    return res.status(400).json({ success: false, result: null, message: 'Role and permissions are required.' });
  }
  if (!NON_OWNER_ROLES.includes(role)) {
    return res.status(400).json({ success: false, result: null, message: 'Invalid role.' });
  }
  const [result] = await models.Permission.upsert({ role, permissions }, { returning: true });
  // Postgres upsert returns the row via RETURNING; keep a fallback for defensiveness:
  const row = result || await models.Permission.findOne({ where: { role } });
  return res.status(200).json({ success: true, result: row, message: 'Permissions updated successfully.' });

const listMy = async (req, res) => {
  const user = req.admin;
  if (user.role === 'owner') {
    const allTrue = Object.fromEntries(Object.keys(DEFAULT_PERMISSIONS).map((k) => [k, true]));
    return res.status(200).json({ success: true, result: { role: 'owner', permissions: allTrue }, message: 'Owner has full access.' });
  }
  const [rolePermission] = await models.Permission.findOrCreate({
    where: { role: user.role },
    defaults: { permissions: DEFAULT_PERMISSIONS },
  });
  const merged = { ...rolePermission.toJSON(), permissions: { ...DEFAULT_PERMISSIONS, ...rolePermission.permissions } };
  return res.status(200).json({ success: true, result: merged, message: 'User permissions fetched successfully.' });
};

module.exports = { list, update, listMy };
```

### TASK 20 — `src/controllers/appControllers/clientController/summary.js`

**Purpose**: Dashboard stats — total clients, new clients this period, active clients (those with at least one invoice).

**Current Mongoose pattern**: `$facet` aggregation with `$lookup` from invoices, `$count`.

**Sequelize implementation** (three separate queries instead of `$facet`):
```js
const { models, Op, sequelize } = require('@/db');
const moment = require('moment');

const summary = async (req, res) => {
  let defaultType = 'month';
  const { type } = req.query;
  if (type && ['week', 'month', 'year'].includes(type)) {
    defaultType = type;
  } else if (type) {
    return res.status(400).json({ success: false, result: null, message: 'Invalid type' });
  }

  const currentDate = moment();
  const startDate = currentDate.clone().startOf(defaultType).toDate();
  const endDate = currentDate.clone().endOf(defaultType).toDate();

  const [totalClients, newClients] = await Promise.all([
    models.Client.count({ where: { removed: false, enabled: true } }),
    models.Client.count({ where: { removed: false, enabled: true, created: { [Op.between]: [startDate, endDate] } } }),
  ]);

  // Active clients = clients that have at least one non-removed invoice
  const activeResult = await sequelize.query(
    `SELECT COUNT(DISTINCT c.id) AS cnt
     FROM clients c
     INNER JOIN invoices i ON i.client_id = c.id AND i.removed = false
     WHERE c.removed = false AND c.enabled = true`,
    { type: sequelize.QueryTypes.SELECT }
  );
  const activeClients = activeResult[0]?.cnt || 0;

  const totalActiveClientsPercentage = totalClients > 0 ? (activeClients / totalClients) * 100 : 0;
  const totalNewClientsPercentage = totalClients > 0 ? (newClients / totalClients) * 100 : 0;

  return res.status(200).json({
    success: true,
    result: { new: Math.round(totalNewClientsPercentage), active: Math.round(totalActiveClientsPercentage) },
    message: 'Successfully get summary of new clients',
  });
};

module.exports = summary;
```

### TASK 24 — `src/controllers/appControllers/invoiceController/create.js`

**Purpose**: Creates invoice + items, sets PDF filename, increments `last_invoice_number`.

```js
const { models, sequelize } = require('@/db');
const { calculate } = require('@/helpers');
const { increaseBySettingKey } = require('@/middlewares/settings');
const schema = require('./schemaValidate');

const create = async (req, res) => {
  let body = req.body;
  const { error, value } = schema.validate(body);
  if (error) {
    return res.status(400).json({ success: false, result: null, message: error.details[0]?.message });

  const { items = [], taxRate = 0, discount = 0 } = value;
  let subTotal = 0;

      { transaction: t }

    invoice.pdf = `invoice-${invoice.id}.pdf`;
    await invoice.save({ transaction: t });

    await models.InvoiceItem.bulkCreate(
      items.map((item) => ({ ...item, invoice_id: invoice.id })),
      { transaction: t }
    );
    return invoice;
  });

  return res.status(200).json({ success: true, result, message: 'Invoice created successfully' });
```

```js
  { replacements: { tz, from, now }, type: sequelize.QueryTypes.SELECT }
);
```
> **Note**: Postgres timezone names come from the standard tz database (e.g. `'Australia/Sydney'`, `'UTC'`) and are shipped with the server — no extra install needed. Unlike MySQL's `CONVERT_TZ`, `AT TIME ZONE` chains naturally: the first `AT TIME ZONE 'UTC'` treats the stored `TIMESTAMP` as UTC, the second converts to the user's zone.

**`topSkus()`** — GROUP BY + ORDER BY + LIMIT → pure Sequelize:
```js
const result = await models.Sales.findAll({
  where: { removed: { [Op.ne]: true }, date: { [Op.gte]: from }, sku: { [Op.ne]: '' } },
  attributes: ['sku', 'product_name', [sequelize.fn('SUM', sequelize.col('quantity')), 'totalQty']],
  group: ['sku', 'product_name'],
  order: [[sequelize.literal('totalQty'), 'DESC']],
  limit: 10,
  raw: true,
});
```

**`employeePerformance()`** — uses `$lookup` from admins collection with `$cond` sums. In Postgres, use `COUNT(*) FILTER (WHERE …)` which is cleaner than conditional SUM:
```js
const result = await sequelize.query(
  `SELECT a.id, a.name, a.role, a.photo,
     COUNT(*) FILTER (WHERE s.date >= :todayStart) AS today,
     COUNT(*) FILTER (WHERE s.date >= :weekStart)  AS week,
     COUNT(*) AS month
   FROM sales s
   INNER JOIN admins a ON a.id = s."createdBy_id"
   WHERE s.removed = false AND s.date >= :monthStart
   GROUP BY a.id, a.name, a.role, a.photo
   ORDER BY month DESC`,
  { replacements: { todayStart, weekStart, monthStart }, type: sequelize.QueryTypes.SELECT }
);
```
> **Note**: Postgres folds unquoted identifiers to lowercase, so camelCase columns created by Sequelize (`createdBy_id`, `settingKey`, etc.) must be **double-quoted** in raw SQL. Sequelize does this automatically in its query builder but not in `sequelize.query(…)` strings — be explicit.

### TASK 47 — `src/handlers/downloadHandler/downloadPdf.js`

**Purpose**: Generates and serves a PDF for an invoice or quote. Uses `mongoose.models[modelName]` to check model existence and fetch the document.

**Change**: Replace `mongoose.models[modelName]` registry lookup with checking `models[modelName]`. Use `models[modelName].findOne({ where: { id } })`.

**Sequelize implementation**:
```js
const custom = require('@/controllers/pdfController');
const { models } = require('@/db');
const fs = require('fs');
const path = require('path');

module.exports = downloadPdf = async (req, res, { directory, id }) => {
  try {
    const modelName = directory.slice(0, 1).toUpperCase() + directory.slice(1);

    if (!models[modelName]) {
      return res.status(404).json({ success: false, result: null, message: `Model '${modelName}' does not exist` });
    }

    const result = await models[modelName].findOne({ where: { id } });
    if (!result) throw { name: 'ValidationError' };

    const fileId = `${modelName.toLowerCase()}-${result.id}.pdf`;
    const folderPath = modelName.toLowerCase();
    const targetLocation = `src/public/download/${folderPath}/${fileId}`;

    const folderDir = path.dirname(targetLocation);
    if (!fs.existsSync(folderDir)) fs.mkdirSync(folderDir, { recursive: true });

    await custom.generatePdf(modelName, { filename: folderPath, format: 'A4', targetLocation }, result);

    return res.download(targetLocation, (error) => {
      if (error) return res.status(500).json({ success: false, result: null, message: "Couldn't find file" });
    });
  } catch (error) {
    if (error.name === 'ValidationError') {
      return res.status(400).json({ success: false, result: null, message: 'Required fields are not supplied' });
    }
    return res.status(500).json({ success: false, result: null, message: error.message });
  }
};
```

## Reference: Universal Translation Cheatsheet

| Mongoose | Sequelize |
|---|---|
| `mongoose.model('X')` | `const { models } = require('@/db'); models.X` |
| `doc._id` | `doc.id` |
| `req.admin._id` | `req.admin.id` |
| `Model.findOne({ _id: id })` | `models.X.findOne({ where: { id } })` |
| `Model.find({ removed: false })` | `models.X.findAll({ where: { removed: false } })` |
| `Model.countDocuments(filter)` | `models.X.count({ where: filter })` |
| `new Model(data).save()` | `models.X.create(data)` |
| `Model.findOneAndUpdate(q, { $set: u }, { new: true })` | `await models.X.update(u, { where: q }); await models.X.findOne(...)` |
| `Model.updateMany(q, { $set: u })` | `models.X.update(u, { where: q })` |
| `Model.insertMany(arr)` | `models.X.bulkCreate(arr)` |
| `Model.deleteMany()` | `models.X.destroy({ where: {} })` |
| `Model.bulkWrite(ops)` | loop + `models.X.update()` in a transaction |
| `{ $inc: { field: 1 } }` | `models.X.increment('field', { by: 1, where: q })` |
| `{ $push: { arr: val } }` | not needed — use FK table |
| `{ $pull: { arr: val } }` | not needed — use FK table |
| `.populate('createdBy', 'name')` | `include: [{ model: models.Admin, as: 'createdBy', attributes: ['name'] }]` |
| `Model.aggregate(pipeline)` | `sequelize.query(rawSQL)` or `findAll` with `fn/col/group/order` |
| `AdminPassword field: user` | `AdminPassword field: admin_id` |
| `{ $setOnInsert: data }` | `findOrCreate({ where: q, defaults: data })` |
| `{ $or: [...] }` | `{ [Op.or]: [...] }` |
| `{ $in: arr }` | `{ [Op.in]: arr }` |
| `{ $ne: val }` | `{ [Op.ne]: val }` |
| `{ $lte: val }` | `{ [Op.lte]: val }` |
| `{ $regex: /q/i }` | `{ [Op.like]: '%q%' }` |
